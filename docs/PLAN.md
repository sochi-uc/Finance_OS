# Strategic Roadmap

## Phase 1: Core Foundation & Execution Engine ✅
- Fastify REST API with Server-Sent Events (SSE) for zero-latency synchronization.
- SQLite with WAL journal mode for ACID-compliant, air-gapped local persistence.
- Zero-build modular frontend architecture (`web/css/style.css`, `web/js/*.js`).
- Apple Human Interface Guidelines (HIG) visual token system and fluid physics engine.
- Progressive Web App (PWA) offline caching via Service Worker.

## Phase 2: Analytics & Tactical Intelligence (In Progress)
- Interactive asset allocation donuts and dynamic dividend cashflow projection calendars.
- Historical candlestick/line visualization terminals with volume analysis.
- Multi-currency liquidity engine (NGN/USD cost-basis tracking).
- Frosted-glass explainer modal system across financial metrics and technical indicators.

## Phase 3: Automated Market Pipeline & Alerts
- Programmatic NGX and global equity price ingestion pipelines.
- Automated quarterly dividend and corporate action reconciliation.
- Encrypted offsite backups and webhook notifications.

## Phase 4: Institutional Hardening
- Passkey / WebAuthn token authentication.
- Cryptographic ledger audit-log immutability.
- Multi-factor portfolio rebalancing simulation engine.
